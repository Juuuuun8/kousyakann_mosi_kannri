# 会社説明用デモ 2026-09-29

## 目的

模試成績表を回収してから、帳票Schemaを登録し、各校舎が安全にアップロードし、管理者が横断分析する将来像を、会社承認前に架空データだけで具体的に示す。

## デモ範囲

- 初期模試: 河合塾・全統共通テスト模試を想定した2回次
- 規模: 架空24人、3校舎、6高校、7科目
- 分析: 全体KPI、回次比較、校舎・高校比較、科目、分野、設問、志望校判定、個人推移、欠損・品質
- 出力: 利用目的と取扱確認を必須にした匿名化ML用CSV
- データ: 氏名、校舎、学校、志望校、点数を含め、すべて生成した架空値

## 接続方式

画面とデモ用Google Sheetsは `scripts/generate-demo-dataset.mjs` が作る同一データセットを利用する。承認前デモでは、非公開Google Sheetsを公開設定にしたり、ブラウザへ資格情報を埋め込んだりしない。そのため画面は静的なSheetスナップショットを読み、Sheetは同じ元データから生成する。

承認後は画面側のデータ取得部をGAS Web Appへ交換する。表示・集計・抑制・CSV契約は維持できるため、画面を作り直さない。

## 会社へ示せること

1. 模試・回次・校舎・学校・科目を切り替えると、全分析が一貫して再計算される。
2. 少人数集団は値を隠し、人数と抑制理由だけを表示できる。
3. 未受験を0点に変換せず、欠損として分母と品質情報を示せる。
4. 教員が次の指導を決めるための比較材料を提示し、自動で指導内容を断定しない。
5. 帳票Schema、正本保存、認証、監査、ML出力を交換可能な契約として分離している。

## デモで行わないこと

- 実在生徒のPDF・氏名・成績の投入
- 平文パスワード保存
- 未承認GASや職場Driveへの本番接続
- デモ用Google Sheetsの一般公開
- 小集団や直接識別子を含むML CSVの生成

## 再現手順

```powershell
npm install --ignore-scripts
node scripts/generate-demo-dataset.mjs
npm run build:demo
npm run verify
```

配備対象は `dist/` のみ。Cloudflare Pagesが `dist/_headers` を読み、CSP、APIレスポンスのno-store、noindex、フレーム拒否等を設定する。ローカル生成したExcelは `outputs/` に置き、Git管理対象外とする。

## 承認後の交換点

- 静的JSON読込をGAS APIへ交換
- 合成データをSheet正本の検証済みACTIVEレコードへ交換
- 合成ログイン画面をPBKDF2 verifier、ロック、セッションCookieを持つGAS認証へ交換
- PDFアップロード画面をSchema判定、抽出、検証、PENDINGからACTIVEへの登録へ接続
