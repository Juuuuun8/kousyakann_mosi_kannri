# デモ画面 PDF根拠監査（2026-09-30）

## 結論

デモ v3 の対応模試は、添付PDFで実抽出を確認した「河合塾・全統共通テスト模試」に限定する。校舎はPDF項目ではなくアップロード時選択、統計値はシステム算出として区別する。旧デモにあった未確認の模試・科目・コース・登録予定人数は使用しない。

## データの由来

| 区分 | デモで扱う情報 |
|---|---|
| PDF直接取得 | 模試名・回次、学校、学年、氏名・受験番号、科目成績、順位・母数、分野別結果、志望校情報、設問マーク |
| 登録時入力 | 所属校舎 |
| システム生成・算出 | PersonID、登録状態、PDFハッシュ、得点率、前回差、平均、中央値、四分位範囲 |
| デモで不使用 | 文理・進路コース、PDFのみでは分からない登録予定人数、未対応模試、日本史・世界史・倫理・政治経済・生物・地学の成績 |

## UI上の防止策

- 「登録状況」でPDF・登録時入力・システム算出・不使用を明示する。
- PDFだけでは未受験者を識別できないため、登録予定数を仮定した進捗率を表示しない。
- 科目はサンプルPDFの教科・総合14項目、分野は確認済み50項目に限定する。
- 架空データの模試回はすべて同一の対応模試定義に属し、将来対応予定の模試を実績として表示しない。
