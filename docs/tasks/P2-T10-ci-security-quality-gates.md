## 2 結果

- Node 22.18とTypeScript 5.9.3を固定し、全workspaceの型検査・契約試験・Git履歴込みセキュリティ検査を`npm run verify`へ統合した。
- CIは依存をlockfileどおり復元し、型エラー、テスト失敗、危険拡張子、既知PII断片、秘密鍵・token・ブラウザ永続化の疑いを検出すると失敗する。
- scan対象から生成物だけを除外し、リポジトリ内の実データ混入を許可しない。

## 3 例外・境界

- OCRによる画像内PII検査は誤検知・取りこぼしを伴うため自動ゲートにせず、リリース前目視監査へ残す。
- GitHubブランチ保護の有効化はリポジトリ設定変更を伴うため、管理者が承認後に行う。
- 依存脆弱性のオンライン照合はネットワークと更新判断が必要なため、リリース時ゲートへ分離する。

## 4 受入試験

`npm run verify`が固定環境で成功し、Git履歴へ禁止ファイル名・既知サンプル断片を入れた検証用fixtureではscannerが失敗すること。
