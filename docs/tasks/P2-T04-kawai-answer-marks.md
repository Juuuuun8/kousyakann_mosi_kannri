## 2 抽出方式

ページ4の各科目ブロックを、`大問番号`、`解答番号`、`正 誤`、`マーク`の4行組として読み取る。解答番号の列中心へ最も近い正誤・マークを対応づけ、続き行で省略された大問番号は同一科目内だけで直前値を継承する。

英語のリーディング・リスニングのように同一水平ブロックに複数科目がある場合は、2つ目の`解答番号`ラベルとその左側の科目見出しを使って分離する。

## 3 正誤コード

| 原表記 | 正規化コード | 意味 |
|---|---|---|
| ○ / 〇 | CORRECT | 正答 |
| × | WRONG | 誤答 |
| △ | PARTIAL | 部分点 |
| S | UNDETERMINED | 正解パターン複数等で正誤表示不能 |
| N | NO_ANSWER | 無解答・マークが薄い等 |
| W | EXTRA_MARK | 余分なマーク |

原表記と正規化コードを併記する。未知記号は推測せず`UNKNOWN_CODE`、印字空欄は`BLANK_ON_REPORT`とする。マーク空欄を数値0へ変換しない。
