## 2 正本化した情報

- 主要科目行の注意記号 `*` / `#` を`attentionCodeRaw`として保持する。
- 共通テスト換算得点は`metric.kawai.common-test-converted-score`として、得点・満点・原科目名を通常の科目成績行へ格納する。
- 私大評価用偏差値は`metric.kawai.private-university-deviation`として、偏差値・評価型原表記を通常の科目成績行へ格納する。
- 帳票印字の過去回成績は`TrendPayload`へ格納し、模試名原表記、科目、得点、偏差値、学力レベルを保持する。過去回の正式なExamEventIDはカタログ照合前なのでnullとする。
- 静的な凡例・説明文はschema文書で管理し、個票ごとの重複データとして保存しない。

## 3 READY条件

次をすべて満たす場合だけ`READY`とする。

- 帳票識別、4ページ役割、全ページ受験番号一致が有効
- 主要科目、換算得点、私大偏差値、成績推移、分野別成績、解答明細が1件以上
- 志望校欄は第1〜第9志望の全枠を識別可能。全枠空欄は0件として正常
- 科目ラベルが既知の定義へ正規化可能
- 全payloadが実行時データ契約へ適合
- 全文raw payloadを含まない

未知ラベルは値を推測せず`REVIEW`、必須領域欠落・ページ混在・構造不一致は`REJECTED`とする。
